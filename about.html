ABOUT THE PROJECT

About ZENVORA

ZENVORA is a web search and website discovery project that brings a public web search, personal website shortcuts, and a small directory of useful online services together in one interface.

What you can do

  • Search the public web when the site owner has configured the external search provider.
  • Create an account to save website addresses to a private library. The site administrator can also access account records.
  • Browse a hand-picked directory of third-party services and links. These services are operated independently and are not endorsed by ZENVORA.
  • Use the optional AI chat when the site owner has configured its service. AI answers may be inaccurate and should be checked.
  • Use the ZENVORA website in a browser or the available Windows desktop wrapper. The online features require an internet connection.
