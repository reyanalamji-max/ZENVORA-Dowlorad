YOUR INFORMATION

Privacy Policy

This policy describes information handled by the ZENVORA application as currently implemented. Hosting, search, AI, browser, and linked-site providers may have their own practices.

Information you provide

  • Account details: if you register, ZENVORA stores your username, account creation time, and a salted password hash. The original password is not stored by the application.
  • Saved websites: website names and URLs you save are stored with your account. They are available to your account and the site administrator. You can remove individual saved websites from your account page.
  • Search terms: the app processes your search request to return matches but does not intentionally save a search-history record. If public web search is enabled, the query is sent to the external search provider to retrieve results.
  • AI messages: when the optional AI service is configured, messages in a chat are sent to Google’s Gemini service to generate a response. ZENVORA keeps the current conversation in the browser page’s memory and does not save it to the account database.

Storage, sessions, and device features

Account records are stored by the application in its server-side data store. Account and administrator sessions use an HttpOnly, SameSite cookie; sessions are held in server memory and expire after eight hours. The application’s current account interface does not provide an account-deletion control. Do not register if you are unwilling to have the account data described above stored.

The website registers a service worker that caches selected static files for app installation and offline handling. Application code does not intentionally store search history in browser storage. Voice input and spoken AI replies use browser speech features; speech recognition may be processed by your browser or its provider, under that provider’s policies.

Third parties and technical requests

When configured, public web search queries are sent to Serper. Optional AI messages are sent to Google Gemini. Search result pages request favicon images from Google’s favicon service, which receives the requested destination domain and normal request metadata. Clicking an external link takes you to that independent service, which may receive your request and use its own cookies or tracking.

The site is hosted by Render. The hosting provider may process connection details and operational logs as part of providing the service. ZENVORA’s application code does not intentionally record search terms in server logs, but hosting-level logging is governed by the host’s policies.

The current application source does not load an AdSense ad-serving script. If advertising or other third-party features are added, this policy should be updated to describe the resulting data handling before those features are enabled.

Retention and choices

Account records and saved website links remain in server storage until removed by you or the site administrator. You can remove saved links from your account page, but account deletion is not currently available through the site. Browser session cookies expire after eight hours; server sessions are also memory-based and may end when the server restarts.

For general project feedback, use the public issue tracker linked on our Contact page; do not post passwords, private saved links, or other sensitive information. This website does not provide a configured private account-deletion request channel.

Changes to this policy

This policy may change when application features or providers change. The updated date below identifies the latest published version.
